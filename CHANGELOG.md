# Changelog

## 0.1.0

- First release with ten built-in skins, from Aurora Flow and Neon Tokyo to Matcha Garden and Cobalt Tide.
- Adds Custom Canvas: local background-image upload, light/dark base mode, independent background, surface, accent, and text colors, plus adjustable image atmosphere.
- Custom Canvas applies its photo through coordinated translucent application tokens, making the wallpaper visible in the live chat view.
- Validate uploaded images through the browser decoder and render the Custom Canvas preview with the original image element.
- Add persistent image framing: drag-to-focus plus zoom, horizontal, and vertical crop controls.
- Adds a bilingual Skin Studio selector to the existing General settings page.
- Uses DeepSeek Harness's public ThemeRuntime; no Harness source or private UI implementation is modified.
